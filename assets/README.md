# Assets

Source files for the app's own marks. Nothing here is licensed under the repository's MIT license; see `NOTICE.md`.

| File | What it is | Used as |
|---|---|---|
| `logo.png` | PerkOS mark | reference |
| `logo-name-verticaly.png` | PerkOS mark with wordmark, vertical | `apps/desktop/icon.png`, `apps/web/public/logo.png` |
| `logo-name-horizontal.png` | PerkOS mark with wordmark, horizontal | reference |
| `Sparky.png` | Sparky, the voice of PerkOS (1254 px master) | `apps/web/public/sparky.png` at 640 px |
| `1claw-round-dark.svg`, `1claw-round-dark-1024.png` | 1Claw mark, for the integration badge | `apps/web/public/1claw.svg` |

Base marks live in `apps/web/public/base/` and come from the Base brand kit (brand.base.org). `Sparky.svg` is not tracked: it is the PNG embedded in an SVG wrapper, not a vector.
