# Code of Conduct

We want this project to be a place where anyone can contribute without harassment. Be respectful, assume good intent, and keep disagreements about the work.

Unacceptable: harassment, discrimination, personal attacks, publishing others' private information, and sustained disruption.

Maintainers may remove, edit or reject contributions and comments that break this, and may ban repeat offenders. Report problems through the private channel described in `SECURITY.md`.

Adapted from the Contributor Covenant, version 2.1.
